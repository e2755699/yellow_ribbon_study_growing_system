# Report font

Noto Sans TC, distributed under the SIL Open Font License in `OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/notosanstc

`NotoSansTC-Regular.ttf` is a static instance of the upstream variable font at
`wght=400`, produced with fontTools. It is bundled so PDF generation works without
a remote font request and contains Traditional Chinese student names.
