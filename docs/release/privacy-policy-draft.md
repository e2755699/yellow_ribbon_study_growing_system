## 1. 適用範圍與服務

黃絲帶成長學習系統（App Store 名稱：yellowribbon study system）供黃絲帶愛網關懷協會及其授權合作人員管理學生資料、每日出席、課堂表現與成長紀錄。帳號由管理員建立，不提供公開註冊。App、帳號及所有功能均免費。

本政策說明使用本 App 時處理的個人資料，包含工作人員輸入的學生、監護人與緊急聯絡人資料。App 供授權工作人員操作，並不代表其中沒有未成年學生資料。

## 2. 處理的資料與用途

實際處理的資料取決於授權人員填寫或上傳的內容，並非每位學生都有下列所有資料。

| 資料 | 處理目的 |
| --- | --- |
| 登入 Email、使用者識別碼及帳號資料 | 登入、辨識使用者及維持帳號存取 |
| 學生姓名、性別、生日、學校、班級地點、身分識別及聯絡資料 | 建立與維護學生紀錄 |
| 監護人及緊急聯絡人的姓名、聯絡方式、工作單位及身分欄位 | 維護照護與緊急聯繫所需紀錄 |
| 家庭、經濟、族群、特殊疾病或特殊學生說明、接送需求 | 記錄服務與照護所需資訊 |
| 興趣、能力評估、學習目標、資源及獎助、課程、介紹與備註 | 學習輔導及成長紀錄管理 |
| 頭像、使用者選擇上傳的照片或檔案 | 學生識別、附件及相關紀錄管理 |
| 每日出席、課堂與品格表現、黃絲帶及成長報表資料 | 記錄與查看學生的學習及出席情形 |
| 畫面與操作事件、裝置或安裝識別資訊、當機與效能資訊，以及 SDK 推估的粗略地區資訊 | 維護 App 功能、分析使用情形及改善穩定性與連線效能 |

使用者應僅輸入服務必要且有權提供的資料。請勿在備註或附件加入與服務無關的敏感內容。

## 3. 雲端服務與資料接收者

App 使用 Google Firebase 的 Authentication 處理登入，Cloud Firestore 儲存與同步業務資料，Cloud Storage 儲存上傳檔案，並使用 Analytics、Crashlytics 與 Performance Monitoring 分析操作、當機和效能。

因此，所輸入的資料及相關技術資訊會依上述用途由相關雲端服務處理；資料可由系統中具相應權限的協會與合作人員存取。不同雲端服務的處理位置可能不同；App 僅在台灣供應，不代表所有資料都只在台灣處理。

目前版本未加入第三方生成式 AI 的學生評估傳送功能。若日後增加向 AI 服務傳送學生資料的功能，會在推出前更新告知內容及相關使用流程。

第三方服務資訊：[Firebase 隱私與安全](https://firebase.google.com/support/privacy)、[Google 隱私權政策](https://policies.google.com/privacy)。

## 4. 裝置功能

上傳頭像或附件時，App 使用系統提供的照片或檔案選擇功能。請只選擇有權提供的內容；實際權限要求依裝置、系統版本及所使用功能而定。

目前版本未提供精確 GPS 定位、通訊錄讀取或廣告投放功能。分析服務仍可能依網路連線資訊推估粗略地區，不等同於使用 GPS 追蹤位置。

## 5. 資料保存與刪除

【發布前待確認：應在此列明協會實際保存學生、監護人與紀錄的期限或判定原則，以及服務結束後的處理方式。不得填寫不存在的自動刪除機制。】

解除安裝 App 不會刪除雲端帳號或學生紀錄。不同種類的資料分別保存在帳號、學生文件、出席／表現紀錄及檔案儲存等位置；資料刪除請求需要依範圍分別處理，不能把單一學生文件刪除視為所有關聯資料已清除。

## 6. 聯絡與資料請求

學生、監護人或帳號使用者如需提出資料查詢、更正或刪除請求，可聯絡 e2755699@gmail.com，由服務負責人受理。

提出詢問時請先提供足以聯繫的資訊與請求概要，避免直接在一般電子郵件寄送完整身分證字號、健康紀錄或其他學生資料。

## 7. 政策更新

本政策更新時，將於政策頁面標示更新日期。若資料處理方式有實質改變，應同步調整 App 內告知及 App Store 的隱私揭露。
