# 學生個人座右銘

- 編輯資料的「個人資料」新增選填座右銘；隨學生儲存在 `students/{id}.motto`。
- 詳情頁上方顯示個人座右銘。舊資料缺少欄位、null、留白或清空，都顯示「每天都是，更棒的自己！」。
- 保留原有配色、星光圖示及文字樣式；較窄畫面改為下方換行顯示，不再隱藏這句話。
- 模型序列化、單筆與列表讀取、表單儲存以及 copyWith 均納入新欄位；不需遷移舊資料。

驗證：20 項相關 Flutter 測試通過，涵蓋舊資料相容、個人座右銘保存、失敗重試、重新編輯、清空恢復預設，以及五種 iPad／分割視窗尺寸的長句換行（1024×768、768×1024、1194×834、834×1194、507×768）。資料寫入流程使用隔離 repository 測試，未寫入真實學生測試文案；尚未做 iPad 實機驗收。

Web 已重新編譯並實際確認：既有學生顯示預設句子，「編輯資料」可見座右銘輸入欄及留白提示，畫面無可見 overflow。針對修改檔案的靜態分析沒有 error／warning；有 8 項既有 info（print 與 if 大括號）。
