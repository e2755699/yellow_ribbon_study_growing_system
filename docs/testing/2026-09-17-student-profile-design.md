# 學生詳細頁參考圖改版

本文件是 2026-09-17 的歷史紀錄。後續已移除 `StudentProfileTheme`，詳情與列表共用 `SystemTheme`，預設頭像也已更新；目前規範見 [Design System](../design-system.md)。

使用者明確指定以提供的奶油黃／橄欖綠參考圖改造學生資料頁。本次範圍為學生詳細頁（查看、新增、編輯），未更換首頁與其他業務頁面的主題。

## 設計與資料

- 淡黃背景、白色圓角卡片、橄欖綠文字、柔和陰影、圓形返回按鈕。
- 個人名片顯示真實姓名、據點、可複製的資料 ID 與頭像。無有效照片時使用姓名首字預設圖，不使用參考圖中的範例人物。
- 四張摘要卡使用黃絲帶、最近一次表現、表現紀錄總數及監護人。沒有把舊資料標成「今日出席」或「本週表現」，也沒有建立範例學號或入學日期。
- 近期表現與學習足跡由既有每日表現 Repository 讀取，按日期由新到舊排列。`StudentActivityCubit` 由路由建立，提供載入中、空資料及失敗重試狀態；讀取歷史失敗不再誤報為零筆。
- 家庭、聯絡人、學習／照顧需求及學生簡介可展開查看；編輯、儲存、頭像、附件操作沿用既有流程。
- `StudentProfileTheme` 只作用於詳細頁；共用版面與頭像元件新增的外觀參數預設保留原行為。

## 驗證

- `flutter test --no-pub --reporter expanded`：60 項通過。
- 新增五種 iPad 尺寸的摘要頁操作驗證；既有表單測試補上儲存後顯示摘要、重新編輯保留資料的檢查。
- 新增近期資料排序與失敗後重試測試。
- `flutter analyze --no-pub --no-fatal-infos` 通過，沒有 error／warning；仍有專案既有 info。後續清理新增檔案的 lint，針對改動檔案分析通過。
- 瀏覽器以既有登入狀態確認實際資料載入，並在 1024×768 與 507×768 檢視卡片及編輯表單。確認返回對話框與不保存離開正常。沒有輸入或儲存真實學生的變更。

Web 預覽已更新。iPad 原生實機仍需後續驗收。
