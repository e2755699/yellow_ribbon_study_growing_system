## 預覽與重跑驗證

本次保留本機 Web 預覽：`http://127.0.0.1:8000/`，未登入會停在登入頁。若背景程序已結束，在專案根目錄使用 PowerShell：

```powershell
& "$env:USERPROFILE/.cache/flutter-sdks/flutter-3.24.5/bin/flutter.bat" run -d web-server --web-hostname=127.0.0.1 --web-port=8000
```

驗證指令（Flutter 3.24.5 / Dart 3.5.4）：

```sh
flutter test --reporter expanded
flutter analyze --no-pub --no-fatal-infos
flutter build web --release
```

若換機，先在根目錄、`packages/ui_component/`、`widgetbook_gallery/` 各執行相容 SDK 的 `flutter pub get`。一般 `flutter analyze` 仍會因既有 info 回傳非零；沒有改規則把診斷藏起來。完整功能清單在 [README](../../README.md)，後續代理工作規範在 [CLAUDE.md](../../CLAUDE.md)。
