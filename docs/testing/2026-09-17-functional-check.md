## 待修正問題

1. **首頁缺少登入攔截**：`lib/flutter_flow/nav/nav.dart` 未將首頁存取與 Firebase 登入狀態連動。應補上登入狀態監聽與路由攔截，再以登出狀態驗證直接網址存取。
2. **建立後遺失 ID**：`StudentDetailCubit.create()` 忽略 `StudentsRepo.create()` 回傳的 ID，仍將原始物件放進狀態。呼叫此 Cubit 流程後，依賴學生 ID 的附件操作無法直接接續。學生詳情頁另有自己的建立流程，需整併核對，不能將此結果直接推論為所有 UI 建立流程均失敗。
3. **建立失敗卻顯示成功**：Repository 可能以 null 表示失敗，Cubit 未檢查結果。應明確發出錯誤狀態並保留表單。
4. **樣板測試缺少 Firebase 隔離**：`test/widget_test.dart` 直接建立 `MyApp`，登入頁 Analytics 初始化觸發 core/no-app；應建立測試替身與必要初始化，再補上畫面斷言。
